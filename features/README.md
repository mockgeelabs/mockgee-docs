# Features

Mockgee SaaS combines API mocking, AI simulation, workspace administration, and runtime observability.

## API Simulation

- [API Mocks](/features/api-projects.md): manage REST and GraphQL mock APIs.
- [REST and GraphQL](/features/rest-graphql.md): create endpoint and operation mocks.
- [Dynamic Mocking](/features/dynamic-mock.md): return different responses for the same endpoint.
- [Request Matcher](/features/request-matcher.md): match by path, query, headers, and body.
- [Fake Data](/features/fake-data.md): generate dynamic values in responses.
- [Default Responses](/guides/default-responses.md): define fallback behavior.
- [Response Mapping](/features/mapping.md): copy request data into responses.
- [Response Delay](/features/delay.md): simulate latency.

## AI Simulation

- [AI Mocks](/features/ai-mocks.md): OpenAI-compatible chat completions and SSE streaming.
- [Tool Calls](/features/tool-calls.md): deterministic agent tool execution.
- [MCP Server Simulation](/features/mcp-server.md): expose selected tools through MCP-compatible endpoints.

## Workspace Tools

- [Import and Export](/features/importers.md): OpenAPI, Postman, and Mockgee native workflows.
- [Dashboard and Metrics](/features/monitoring.md): usage, latency, AI stream metrics, and unmatched requests.
- [Webhooks](/features/webhooks.md): dispatch signed callbacks when mocks match.
- [API Keys](/features/api-keys.md): workspace-scoped automation credentials.
- [Custom Domains](/features/custom-domains.md): serve mock runtime traffic from your own domains.
- [Billing and Plans](/features/billing.md): Free, Pro, and Enterprise plan model.
- [Audit Log](/features/audit.md): review workspace and security-sensitive events.
