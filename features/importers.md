# Import and Export

Mockgee can create API Mocks from existing API artifacts.

## Supported Imports

- OpenAPI / Swagger
- Postman Collection v2
- Mockgee native export

Imported endpoints become normal Mockgee API Mocks and can be edited after import.

## Import a Specification

1. Open **Build -> API Mocks**.
2. Choose **Import**.
3. Select the import format.
4. Upload the file.
5. Review the created mock API and endpoints.
6. Use endpoint cURL samples to test the runtime URL.

## Native Export

Use native export to move mocks between workspaces or keep a workspace backup.

1. Open **Build -> API Mocks**.
2. Select the export action for a mock API or workspace.
3. Download the native JSON export.
4. Import the file into another workspace when needed.

Native export preserves Mockgee-specific project metadata, endpoints, responses, and matching behavior.
