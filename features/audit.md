# Audit Log

The audit log records important workspace activity so administrators can understand who changed configuration and when.

## Where to Find It

Open **Administration -> Audit**.

## What Is Tracked

Audit events include security-sensitive and administration actions such as:

- sign-in failures
- user and membership changes
- API key changes
- workspace administration changes
- tool and MCP configuration changes

Audit metadata is bounded and sensitive headers are redacted.

## Common Uses

- Review unexpected workspace changes.
- Confirm who created or removed an API key.
- Investigate repeated authentication failures.
- Support compliance reviews for team workspaces.
