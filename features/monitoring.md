# Dashboard and Metrics

The Mockgee dashboard focuses on runtime signal first: mock invocations, latency, AI stream activity, and unmatched requests.

## Invocation Stats

The top dashboard area shows mock API invocation stats, including:

- total invocations
- average latency
- top mock hits
- AI streaming requests, chunks, generated tokens, duration, and disconnects when AI stream traffic exists

## Project and Endpoint Overview

Project counts, endpoint counts, and method breakdowns are shown lower on the dashboard so the top area stays focused on runtime activity.

## Unmatched Requests

Mockgee tracks common unmatched method/path samples. Use these insights to create missing endpoints when clients call paths that are not mocked yet.

## Usage Rollups

Runtime counters are rolled up for workspace reporting and plan usage. This helps teams understand daily traffic without storing full request traces by default.
